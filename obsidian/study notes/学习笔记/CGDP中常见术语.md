#术语
**Agentic Memory**
简单来说，**Agentic Memory 是专门为 AI 代理（Agent）设计的、使其能够像人类一样拥有“过去、现在与未来”的记忆系统。**

普通的 LLM 只有“上下文窗口”（Context Window），对话一长或开启新对话就会“失忘”。而 Agentic Memory 的存在，让 AI 代理能够记住所学知识、沉淀历史经验、了解用户偏好，并能在长期的、复杂的、跨渠道的任务中保持行为的连贯性。

**大语言模型代理 (LLM Agent)**，简单来说，就是以大语言模型为“大脑”的核心，能够自主感知环境、进行思考推理，并调用工具来执行复杂任务的**智能软件系统**。

传统的 LLM（如普通的 ChatGPT 界面）通常是“被动问答式”的：你输入一句话，它回复一句话。而 LLM Agent 则具备了“主动性”，你给它一个复杂的终极目标，它能够自己拆解步骤、查阅资料、编写代码，直到把任务搞定。

### 1. 为什么需要“观测函数”？（完全可观察 vs 部分可观察）

在传统的马尔可夫决策过程（MDP）中，环境是完全可观察（Fully Observable）的。

- _例子：下围棋。_ 棋盘上所有棋子的位置（环境的真实状态 $S$）是一览无遗的。代理不需要猜测，它看到的直接就是真实状态。
    

然而，在现实世界或复杂的 AI 任务中，环境通常是部分可观察（Partially Observable, POMDP）的。

- _例子：玩《王者荣耀》或《迷雾迷踪》游戏。_ 整个地图上敌人的位置、血量是客观存在的真实状态（State, $S$），但你的屏幕上（视野内）只能看到迷雾之外的一小块区域。这一小块区域，就是你的**观测（Observation, $O$）**。
    

### 2. 观测函数的定义

**观测函数（通常记作 $O$ 或 $Z$）** 是一个概率映射。它描述了：**在环境处于某种特定真实状态 $S$ 且代理采取了动作 $A$ 的情况下，代理接收到某种特定观测信号 $o$ 的概率。**

数学表达式通常写为：

$$O(o \mid s', a) = P(o_t = o \mid s_{t} = s', a_{t-1} = a)$$

它回答了这样一个问题：如果世界现在的真实状态是 $s'$，且我刚刚执行了动作 $a$，那么我的传感器/眼睛有多大的概率会看到现象 $o$？

大语言模型（如 GPT-4）虽然聪明，但有两个致命缺点：

1. **知识滞后**：它只知道训练截止日期之前的数据。
    
2. **不知道私有知识**：它不知道你们公司的产品说明书、退换货政策或内部代码。
    

**RAG 的出现就是为了解决这个问题。** 它的工作流程可以分为三步（“查-喂-写”）：

- **R（Retrieval - 检索）**：当用户问一个问题时（例如：“我的路由器红灯闪烁怎么办？”），系统首先去公司的**私有知识库**（通常是矢量数据库）里搜索与“路由器红灯闪烁”最相关的产品手册片段。
    
- **A（Augmented - 增强）**：系统把搜索出来的精准原始资料，和用户的提问拼接在一起。这时候，提示词（Prompt）就变成了：“_请阅读以下参考资料：[资料A：红灯闪烁代表硬件故障，需重置...]。现在请回答用户的问题：我的路由器红灯闪烁怎么办？_”
    
- **G（Generation - 生成）**：大模型阅读了这些“小抄（参考资料）”后，组织语言，生成一个既符合人类习惯、又绝对准确的回答。
    

**人话解释**：传统的 LLM 像是**闭卷考试**，容易胡思乱想（幻觉）；而采用了 RAG 技术的 LLM 则是**开卷考试**，看着标准答案组织语言，准确率极高。



**POMDP** 是 **Partially Observable Markov Decision Process** 的缩写，中文通常翻译为**部分可观察马尔可夫决策过程**。

它是人工智能、强化学习和机器人学中一个非常核心的**数学决策框架**。简单来说，它是用来解决“在信息不完整、充满不确定性的世界里，智能体（Agent）应该如何做出一连串最佳决策”的问题。


### POMDP 的核心解法：信念状态 (Belief State)

因为智能体看不到世界的全貌，它就必须根据**过去的所见所闻（历史观测）**，在脑子里对自己当前所处的处境做一个估算和概率统计。这个在脑子里形成的“主观推测”，就叫做 **Belief State（信念状态）**。

- 智能体不再根据“客观世界是什么”做决策，而是根据“我以为、我猜测现在世界是什么样”（Belief）来做决策。
    

> **论文里的对应关系：** 论文里提到的 **PBBS（基于谓词的信念状态）**，其实就是大模型利用“自然语言笔记”去模拟 POMDP 中的这个 **Belief State**。大模型一边搜，一边在笔记上更新：“_通过刚才的搜索（Observation），我现在有 90% 的把握确定 Bug 在 A 模块，接下来我应该去验证 B 模块_”。


**Jaccard 相似度（Jaccard Similarity Index，杰卡德相似度）**，是一个在计算机科学、数据挖掘和自然语言处理（NLP）中非常常用的、用来衡量**两个集合相似程度**的数学指标。

Jaccard 相似度的核心思想非常简单：**两个集合共同拥有的元素（交集），占它们所有元素总和（并集）的比例。**

数学公式为：

$$J(A, B) = \frac{|A \cap B|}{|A \cup B|}$$


### UPR（唯一段落率）就是用来量化“新信息流入速度”的指标：
- **核心原理**：AI 代理每次使用工具搜索（如执行 BASH 或 Web 检索），都会返回一些文本块或段落（Passages）。系统会把当前步 $t$ 检索回来的所有段落，与过去 $t-1$ 步里**所有见过的历史段落**进行比对。
    
- **计算公式**：
    
    $$\text{UPR} = \frac{\text{当前步返回的、且在过去从未出现过的【新段落】数量}}{\text{当前步返回的【总段落】数量}}$$
### 1. PBBS (Predicate-Based Belief State) —— 静态的数据结构

- **中文名称**：基于谓词的信念状态。
    
- **它是什么**：它是大模型大脑里的**记忆实体/数据结构（Data Structure）**。
    
- **它的职责**：负责把庞大的、装不下的外部世界（如整个代码库），高度压缩成一连串离散的、小巧的**逻辑命题列表（谓词）**。
    
- **它的内容**：它里面只存结构化的干货，比如：
    
    - _已证事实（Resolved Predicates）_：`{"函数A在主线程运行": True}`
        
    - _未知线索（Open Predicates）_：`{"函数A是否会导致内存泄漏": 未知}`
        
- **一句话比喻**：它是 AI 侦探手里拿的那本“线索笔记本”，上面密密麻麻写满了“已知线索”和“有待确认的嫌疑点”。
    

### 2. PBAI (Predicate-Based Adaptive Identification) —— 动态的控制算法

- **中文名称**：基于谓词的自适应识别。
    
- **它是什么**：它是驱动 AI 代理运行的**核心算法循环/控制流（Control Loop / Algorithm）**。
    
- **它的职责**：负责规定 AI 代理在每一步“先干什么、后干什么”，并指导它**如何去读写和更新**上面那个“笔记本（PBBS）”。
    
- **它的内容**：它是一个严格的 **4 步闭环死循环**（我们在 Algorithm 1 看到的伪代码）：
    
    1. **Stop?（看笔记）**：翻开 PBBS 笔记本，看核心问题解开没有？解开了就停机。
        
    2. **Select Action（做假设）**：盯着 PBBS 里“未解开的难题”，决定下一步去执行什么搜索命令（采样动作）。
        
    3. **Observe（查资料）**：按下回车，去外部环境捞回一小块文本线索。
        
    4. **Update Belief（改笔记）**：用捞回来的线索，去**更新和涂改 PBBS 笔记本**的内容。
        
- **一句话比喻**：它是 AI 侦探脑子里的“办案标准作业程序（SOP）”，指导他什么时候该看笔记本，什么时候该出门搜证。 

### **Python REPL** 是 **Python Read-Eval-Print Loop（读取-求值-输出-循环）** 的缩写，中文通常叫 **Python 交互式解释器**（或者 Python 交互式命令行）。

简单来说，它就是你打开终端（Terminal）输入 `python` 并回车后，出现的那个带有 `>>>` 符号的**实时交互界面**。

在 LLM 代理（Agent）的论文语境中，Python REPL 经常被作为 Agent 可以调用的**最核心工具之一**（比如让 AI 具备执行代码和数学计算的能力）。

## **Agentic Harness**（通常翻译为 **“智能体马具”**、**“代理沙箱”** 或 **“智能体运行容器/基座”**）是目前 AI 行业（特别是 2025–2026 年）非常核心的一个技术概念。

$$\text{Agent (智能体)} = \text{Model (大模型)} + \text{Harness (容器外壳)}$$

如果一个大模型（如 GPT-4、Claude 3.5 或 Qwen）只在聊天窗口里回答问题，它只是一个**单次响应的聊天机器人**；但如果把它套进一个 **Agentic Harness** 里，它就变成了一个**能够自主在真实世界中执行复杂任务的 AI Agent**。

## 🛠️ Agentic Harness 里面装了什么？

一个完整的 Agentic Harness 是包裹在 LLM 外层的一套**运行时软件基础设施（Runtime Infrastructure）**。它主要由以下几个核心机制组成：

1. **工具注册与执行引擎（Tool Execution Engine）**
    
    - 模型本身只能生成文本，不能“点击网页”或“运行代码”。Harness 负责把真实的 API、数据库、文件系统注册为结构化工具，在模型发出“我想调用某工具”的指令时，Harness 去真实世界中执行，并将结果喂回给模型。
        
2. **安全沙箱环境（Sandboxes）**
    
    - 智能体运行代码具有破坏性。Harness 提供了安全的隔离环境（如 Docker、E2B 安全沙箱），限制 AI 的网络访问权限和文件读写边界，防止它“删库跑路”。
        
3. **记忆与上下文管理（Memory & Context Management）**
    
    - 大模型的上下文窗口是有限的。Harness 负责维护长期记忆和短期记忆，动态对冗余的历史记录进行压缩、摘要、归档，防止模型因上下文太长而产生“长文本遗忘”。
        
4. **控制流与自主循环（Orchestration Loop & Stopping Conditions）**
    
    - 负责驱动 Agent 的“思考-行动-观察（ReAct）”循环。同时，它还设置了“拉闸机制”（如**程序化耗尽门**），当检测到 Agent 在死循环或者疯狂刷 Token 时强行中断。
        
5. **状态持久化（State & Session Management）**
    
    - 支持任务的**中断与恢复**。如果 Agent 在跑一个需要几小时的复杂漏洞修复任务，中间网络断了，Harness 能够保存当前的变量和进度，在连接恢复后继续执行，而不需要重新花钱跑一遍。



## **汤普森采样 (Thompson Sampling)**，又称**后验抽样 (Posterior Sampling)**，是解决机器学习和强化学习中**多臂老虎机问题 (Multi-Armed Bandit, MAB)** 的一种经典概率算法。

它的核心思想非常朴素且强大：**通过贝叶斯推断，在“探索 (Exploration)”与“利用 (Exploitation)”之间实现完美的自适应平衡。**

**在 Agentic Harness 中（如 PBAI 框架）：** Agent 在面对未知的环境时（例如在执行一段未知的代码或探索一个漏洞），无法准确计算下一步哪条指令最有效。

此时，Agent 可以把“生成不同的检索词/执行不同的 BASH 命令”看作是摇动不同的老虎机。基于**基于谓词的信念状态 (PBBS)**，Agent 会对各种探索路径维护一个后验概率，利用**汤普森采样**选择下一步的动作。这既能防止 Agent 陷入无意义的鬼打墙（Exploitation），又能引导它以最小的代价试探出正确的解题方向（Exploration）。
